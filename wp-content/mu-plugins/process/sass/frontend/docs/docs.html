Alerts

Alerts use intent aliases from the token layer.

i
Information
Use `.ui-alert-info` for neutral information.
v
Success
Use `.ui-alert-success` after a completed action.
!
Warning
Use `.ui-alert-warning` when attention is needed.
!
Error
Use `.ui-alert-error` for blocking or failed states.
Helpers

General Utilities

Small helpers cover display, position, z-index, sizing, image fill, and rounded corners.

.d-flex

Sets `display: flex`.

.relative .absolute

Positioning helpers for layered UI.

.z-0 .z-10 .z-50

Simple stacking helpers.

.w-full .h-full

Set width or height to 100%.

.image-fill

Makes child images cover the available area.

.mx-auto

Centers block-level elements horizontally.
